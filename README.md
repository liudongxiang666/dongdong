# 三国群英传

这是一个纯静态、可离线运行的三国题材 H5 策略 PWA 游戏。

## 功能

- 主城建筑升级：主公府、屯田所、木场、石场、校场
- 粮食、木材、石料、铜钱资源体系
- 离线收入与本地存档
- 武将招募、晋升与战力统计
- 城池征伐、资源采集、任务奖励
- 手机竖屏界面与 PWA 安装支持

## 本地运行

由于浏览器安全限制，建议通过 HTTP 服务运行：

```bash
python3 -m http.server 4173
```

打开 `http://localhost:4173`。

## GitHub Pages

合并到仓库后，在仓库设置中启用 Pages：选择部署分支 `main`，目录选择 `/ (root)`。
